# StudyFlow · 学程 —— 大学生学习与项目管理平台

> 面向大学生的 **“目标制定 → 项目规划 → 任务执行 → 进度统计 → 周期复盘”** 全链路个人学习与工程实践管理平台。

## 1. 项目简介

**StudyFlow（学程）** 旨在解决大学生在同时推进课程学习、程序设计竞赛训练（如蓝桥杯、码蹄杯、天梯赛）与个人软件开发项目时面临的**任务分散、长期目标难拆解、项目进度不透明、缺乏周期复盘**四大痛点。

区别于普通的待办清单（To-Do List），StudyFlow 将每一天的具体任务与阶段性项目、中长期学习/职业目标关联起来，并通过每周结构化复盘沉淀真实可追溯的成长轨迹。

---

## 2. 核心功能模块 (MVP)

| 模块 | 路由 | 核心能力 |
| :--- | :--- | :--- |
| **账户与安全隔离** | `/login` | 邮箱注册/登录/退出、路由鉴权保护、多用户数据严格隔离（PostgreSQL RLS + 本地持久化双引擎） |
| **学习总览** | `/dashboard` | 今日待办数、逾期未完成警示、进行中项目实时进度条、任务完成率汇总 |
| **学习目标** | `/goals` | 长期目标创建、编辑、状态流转（进行中/已完成/已暂停）及关联项目追踪 |
| **项目管理** | `/projects`<br/>`/projects/:id` | 项目创建与目标关联、基于子任务自动计算完成率（如 `3/5 -> 60%`）、删除项目保留任务并自动解绑 |
| **任务中心** | `/tasks` | 任务增删改查、状态切换（`todo`/`doing`/`done`）、优先级、计划日期与逾期高亮提醒、多维筛选 |
| **每周复盘** | `/reviews` | 按自然周（`week_start`）记录成果、问题与下周计划，同周自动更新覆盖（Upsert 防重）与历史时间线 |

## 3. 技术栈

- **前端框架**：React + TypeScript + Vite + React Router
- **样式方案**：Tailwind CSS（桌面端左侧导航优先 + `390px` 移动端窄屏自适应）
- **后端与数据持久化**：
  - **云端生产模式**：Supabase（Supabase Auth + PostgreSQL + Row Level Security 行级安全策略）
  - **本地演示模式**：内置零配置 `LocalPersistenceRepository`（完整复刻外键解绑、同周唯一约束与跨用户隔离，内置竞赛生真实演示数据，支持离线秒开演示）
