# 03 - 页面结构、路由与交互设计 (Pages & UI Architecture)

> **项目名称**：StudyFlow（学程）—— 大学生学习与项目管理平台  
> **文档版本**：v1.0（第一阶段冻结版）  
> **制定日期**：2026-10-30  
> **设计原则**：桌面端优先（左侧固定导航 + 右侧自适应主内容区），同时完整适配 `390px` 移动端视口（顶部汉堡菜单抽屉/底部导航 + 单列响应式卡片，无横向滚动条溢出）。

---

## 1. 路由规划与访问权限表

| 路由路径 | 页面名称 | 访问权限 | 核心视图组件 | 页面核心职责 |
| :--- | :--- | :---: | :--- | :--- |
| `/` | 根路由重定向 | 公开/重定向 | `RootRedirect` | 已登录跳转 `/dashboard`，未登录跳转 `/login` |
| `/login` | 登录与注册页 | 公开（已登录跳 `/dashboard`） | `LoginPage` | 邮箱密码登录/注册切换、表单校验、演示账号快捷体验入口 |
| `/dashboard` | 学习总览页 | 需登录 | `DashboardPage` | 4 项核心指标卡片、今日待办与逾期任务速览、进行中项目进度看板 |
| `/goals` | 学习目标页 | 需登录 | `GoalsPage` | 目标列表（按状态分组/筛选）、新建/编辑目标弹窗、关联项目统计 |

## 2. 全局应用骨架设计 (App Shell)

### 2.1 桌面端布局 (`>= 768px`)
采用经典的 **Left Sidebar（固定宽度 `256px`） + Main Content（自适应 `flex-1`，最大内容区 `1200px` 居中）** 结构：

```text
+-----------------------------------------------------------------------------------+
|  StudyFlow · 学程         |  页面主标题 (如：学习总览 Dashboard)    [+ 快捷新建]  |
|  大学生学习与项目管理      |  副标题：今天是 2026年10月30日 星期五                 |
|---------------------------+-------------------------------------------------------|
|  [导航菜单]                |  +-----------+ +-----------+ +-----------+ +-------+  |
|  * 学习总览 (/dashboard)  |  | 今日待办  | | 逾期提醒  | | 进行中项目| | 完成率|  |
|  * 学习目标 (/goals)      |  |     5     | |     1     | |     2     | |  68%  |  |
|  * 我的项目 (/projects)   |  +-----------+ +-----------+ +-----------+ +-------+  |
|  * 任务中心 (/tasks)      |                                                       |
|  * 每周复盘 (/reviews)    |  +-------------------------+ +---------------------+  |
|                           |  | 今日聚焦与逾期任务      | | 进行中项目进度      |  |
|---------------------------|  | [ ] 编写数据库RLS策略   | | StudyFlow MVP   60% |  |
|  [数据模式状态指示器]      |  | [!] 补交算法复盘总结    | | [==========------]  |  |
|  当前用户: stu@edu.cn     |  | [x] 完成PRD需求分析文档 | | 蓝桥杯省赛冲刺  75% |  |
|  [切换/重置演示] [退出]   |  +-------------------------+ +---------------------+  |
+-----------------------------------------------------------------------------------+
```

### 2.2 移动端窄屏布局 (`390px` 视口适配，对应 `AC-12`)
- **防溢出保障**：全局根容器设置 `min-h-screen overflow-x-hidden`，所有卡片、表格、筛选栏在 `< 768px` 下自动流式折行（`flex-wrap` / `grid-cols-1`）。
- **导航交互**：左侧边栏在移动端收起为顶部导航栏（含品牌标识 + 汉堡菜单按钮），点击展开全屏/侧滑导航抽屉；所有操作按钮最小点击热区不小于 `36px × 36px`。

## 3. 各页面详细结构与交互说明

### 3.1 登录与注册页 (`/login`)
- **左侧/顶部品牌区**：展示 `StudyFlow · 学程` 品牌定位——“目标制定 → 项目规划 → 任务执行 → 进度统计 → 周期复盘”五大步骤价值说明。
- **右侧/核心认证卡片**：
  - 顶部 Tab 切换：`登录账号` / `注册新账号`。
  - 输入框：邮箱地址（`email`）、密码（`password`），带实时格式校验。
  - **比赛演示辅助面板（可折叠/置于卡片底部）**：
    - 清晰显示当前数据引擎状态（`Supabase 云端模式` 或 `本地持久化双用户隔离模式`）；
    - 提供 **`一键登录：竞赛生主账号（含真实竞赛与项目数据）`** 与 **`一键登录：测试用户 B（用于验证 AC-10 跨用户数据隔离）`** 快捷按钮，确保评委或同学试用时无需繁琐注册即可体验全流程及验证用户隔离。

### 3.2 学习总览页 (`/dashboard`)
- **区块 1：核心数据统计横幅（4 张统计卡）**
  - 今日待办数、逾期未完成数（若 `> 0` 显示红色警示边框）、进行中项目数、总体任务完成率。
- **区块 2：今日任务与逾期督办区（左侧主栏）**
  - 自动聚合 `planned_date == 今日`、`due_date == 今日` 或 `已逾期未完成` 的任务。
  - 每条任务展示：状态切换按钮（待办/进行中/已完成）、任务标题、所属项目标签、优先级徽章、计划/截止日期及红色 **`已逾期`** 标记。
  - 提供“查看全部任务 →”跳转 `/tasks`。
- **区块 3：进行中项目进度区（右侧副栏）**
  - 展示所有 `status === 'active'` 的项目卡片。
  - 每个项目显示名称、关联的学习目标名称、已完成/总任务数（如 `3/5`）、动态百分比进度条（如 `60%`），点击项目卡片进入 `/projects/:id`。

### 3.3 学习目标页 (`/goals`)
- **顶部操作栏**：状态筛选标签（`全部` / `进行中` / `已完成` / `已暂停`） + `新建学习目标` 按钮。
- **目标卡片列表**：
  - 展示目标标题、状态徽章、目标达成日期（`target_date`）、目标描述。
  - 底部展示该目标下已关联的项目列表（显示各项目名称与当前完成率，点击可直接跳转到对应项目详情）。
  - 操作区：快速切换状态下拉框、`编辑` 按钮、`删除` 按钮（带确认提示）。
- **新建/编辑目标模态框**：表单包含目标名称（必填）、目标描述、目标日期、状态选择。

### 3.4 我的项目页 (`/projects`) 与项目详情页 (`/projects/:id`)
- **我的项目列表页 (`/projects`)**：
  - 顶部筛选：按项目状态筛选（`全部` / `进行中` / `已完成` / `已搁置`）、按所属学习目标筛选 + `新建项目` 按钮。
  - 项目卡片：展示项目名称、关联的目标标签（或“独立项目”）、项目说明、截止日期、任务完成进度条（无任务时显示 `暂无任务`，有任务时精确显示百分比，如 `60% (3/5)`）。
  - 卡片操作：`进入详情`、`编辑`、`删除`（明确提示保留原有任务并解除关联）。
- **项目详情页 (`/projects/:id`)**：
  - 面包屑导航：`我的项目` > `项目名称`。
  - 项目概览头部：展示项目标题、状态切换器、所属学习目标、截止日期、项目描述，以及醒目的**大号项目完成率进度条**。
  - 项目专属任务区：
    - 顶部提供 **页内快速新建任务表单/按钮**（默认自动绑定当前 `project_id`）；
    - 状态过滤（`全部` / `待办` / `进行中` / `已完成`）；
    - 任务列表：每次勾选完成或新增/删除任务，上方项目进度条立即重新计算并动画过渡更新。

### 3.5 任务中心页 (`/tasks`)
- **多维筛选工具栏**：
  - 视图 Tab：`全部` | `今日任务` | `已逾期` | `待办` | `进行中` | `已完成`；
  - 下拉过滤：按所属项目过滤（含“全部项目”“未关联项目的独立任务”及各个具体项目）、按优先级过滤（`高` / `中` / `低`）、搜索框。
- **任务列表项**：
  - 状态流转控件：支持一键勾选完成，或下拉切换 `todo`（待办）/ `doing`（进行中）/ `done`（已完成）；
  - 信息展示：标题、所属项目可点击标签、优先级颜色徽章（高-红、中-琥珀、低-蓝灰）、计划日期 `planned_date`、截止日期 `due_date`（若逾期且未完成，显示红色 `已逾期` 徽章）；
  - 操作按钮：编辑任务、删除任务。

### 3.6 每周复盘页 (`/reviews`)
- **顶部周期控制栏**：
  - 自然周选择器（自动将所选日期对齐到所在周的周一 `week_start`，并显示如 `2026-10-26 至 2026-11-01 (本周)`）。
  - 若当前选中周已有记录，显示绿色徽章 `本周已归档（保存将直接更新原记录）`；若无记录，显示 `本周待填写`。
- **双栏主体区**：
  - **左栏：当周复盘表单（支持 Create / Upsert）**：
    1. `本周成果 (achievements)`：记录完成的竞赛专题、项目模块或课程收获；
    2. `遇到的问题与不足 (problems)`：记录调试卡点、工程经验不足或时间管理问题；
    3. `下周改进计划 (next_plan)`：制定下一周期的具体行动项；
    - 底部按钮：`保存本周复盘`（同一 `user_id + week_start` 自动更新覆盖原记录，绝不产生重复记录）。
  - **右栏：本周数据参考 + 历史复盘时间线**：
    - 上半部分自动列出该自然周内完成的任务清单及统计数字，供写复盘时对照；
    - 下半部分按 `week_start` 倒序排列历史所有周复盘卡片，点击任意历史周可回填查看或修改。
